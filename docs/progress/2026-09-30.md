## Work streams

### 1. Continuous scanning and resource management

The Electron companion now uses an independent background agent, persistent clamd INSTREAM scanning, settled high-risk file watching, durable queue/outbox recovery, CPU/memory/battery/idle policies, timed pauses and optional service hosting. Packaged runtime, real ClamAV, restart recovery and host crash cleanup were exercised.

### 2. Detection layers and quarantine

The release bundles pinned ClamAV, YARA-X, Radare2 and osquery resources with licenses. Optional YARA community rules are revision-pinned, compiled, probed and author-attributed before activation; Radare2 findings and osquery behavior snapshots are review evidence. Confirmed ClamAV threats can be hash-verified and quarantined by the background agent, with durable UI alerts and restore/recheck operations.

### 3. Release and documentation

README, continuous-scanning, detection-layer, Windows trust, third-party notices and v1.3.0 release notes document behavior and limits. The unsigned preview installer and corresponding source archives are published at the GitHub v1.3.0 release with SHA-256 checksums.
